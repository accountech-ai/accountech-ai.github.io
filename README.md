# Accountech AI — עמוד נחיתה

עמוד הנחיתה של מועדון Accountech AI (התוכנית לחשבונאות, אוניברסיטת רייכמן),
מיועד לקישור בביו באינסטגרם.

חי בכתובת: https://idoben50-cloud.github.io/accountech-ai/

`index.html` הוא קובץ אחד עצמאי — כל הלוגואים והגרפיקה מוטמעים בתוכו.
אין לערוך אותו ידנית: הוא נבנה מהמקור שבתיקיית העבודה של המועדון ב-

    landing/index.html   →   python3 landing/build.py   →   landing/dist/

ואז מועתק לכאן.
